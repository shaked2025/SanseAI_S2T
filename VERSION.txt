================================
CHANGELOG
================================

Version 1.0.0 (Initial Release)
--------------------------------
Release Date: November 12, 2025

Features:
- Real-time speech-to-text transcription using OpenAI Whisper
- Multi-speaker identification and diarization
- Live video capture with snapshot capability
- Modern GUI with tkinter
- Audio level monitoring
- Export transcripts to text files
- Configurable settings via YAML
- Complete offline operation (no third-party APIs)
- Support for 5 Whisper model sizes (tiny, base, small, medium, large)
- Color-coded speaker identification
- Cross-platform support (Windows, macOS, Linux)

Components:
- Audio capture module with voice activity detection
- Video capture module with OpenCV
- Speech-to-text engine with Whisper integration
- Simplified speaker diarization
- Full-featured GUI application
- Configuration management
- Installation helper
- Component testing suite

Documentation:
- Comprehensive README
- Quick start guide
- Detailed usage guide
- Troubleshooting guide
- Inline code documentation

System Requirements:
- Python 3.8 or higher
- 4GB RAM minimum (8GB recommended)
- Webcam and microphone
- ~2GB disk space for models and dependencies

Supported Platforms:
- Windows 10/11
- macOS 10.14+
- Linux (Ubuntu 18.04+, Debian, Fedora, etc.)

Known Limitations:
- Speaker diarization uses simplified algorithm (for advanced, use pyannote.audio)
- Best performance with one speaker at a time
- Requires initial internet connection to download models
- GPU acceleration not implemented in this version
